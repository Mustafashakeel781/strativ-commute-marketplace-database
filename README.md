# Strativ Commute Marketplace Database

## Overview

This project contains a relational database design for a recurring-commute marketplace.

The system manages users, providers, services, routes, seat requests, bookings and reviews.

## Main Entities

- Users
- Providers
- Services
- Routes
- Seat Requests
- Bookings
- Reviews

## Project Goals

- Design a relational database
- Use primary and foreign keys
- Apply database constraints
- Write SQL queries using joins, filtering and grouping
- Create database views
- Recommend an index
- Create an ER diagram
- Apply normalization principles

## Project Structure

- `schema.sql` - Database tables and constraints
- `seed.sql` - Synthetic sample data
- `docs/course-notes.md` - Learning notes
